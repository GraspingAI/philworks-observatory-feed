# Philosophy Works Observatory Feed

Public, machine-readable collection statistics for the [Philosophy Works](https://philworks.org) AI hiring investigation.

## Data

The daily publishing workflow places a single JSON file at the repository root:

- [`ai-sector-monitor.json`](./ai-sector-monitor.json) — collection timestamps, board coverage and completeness, the worldwide aggregate posting count for the 23-employer main panel when collection is complete, and a seven-day change only when the underlying observations are comparable.

The separate six-employer data-and-evaluation group is reported in coverage but excluded from the main-panel posting total. No raw job listings, employer-level records, private review notes, or philosophy-specific research findings are distributed here.

**Automated observations are not human-reviewed findings.** The figures reflect selected public job boards at recorded observation times; they are not a comprehensive measure of hiring, employment, or demand for philosophers. For interpretations and reviewed findings, see the [Philosophy Works website](https://philworks.org).

The feed file will appear after the publication workflow has been configured and run successfully.
